# 一键开启

操作文件：[ops/enable-root.ps1](../ops/enable-root.ps1)

顺序：

1. 没有 `ops/config.json` 就从 example 复制并停止；填写本机参数，并按 [ssh/README.md](../ssh/README.md) 准备密钥和可信主机文件后重试。
2. [01-check-wlan.ps1](../ops/01-check-wlan.ps1)
3. 直接 [04-ssh-login.py](../ops/04-ssh-login.py)。已通则结束（本启动 sshd 还在）。
4. 不通则 [03-send-e3.py](../ops/03-send-e3.py)，等待源端口空闲后再 SSH。
5. JSON 落到 `sessions/<UTC>/`。

```powershell
# 在仓库根目录执行
.\ops\enable-root.ps1
```

源端口等待：[ops/wait_7878.py](../ops/wait_7878.py)。被占时死等配置超时，绝不改用临时端口。
