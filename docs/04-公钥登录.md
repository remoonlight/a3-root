# 公钥登录

操作文件：

| 文件 | 作用 |
|---|---|
| [ops/04-bind7878-proxy.py](../ops/04-bind7878-proxy.py) | OpenSSH ProxyCommand，绑 7878 |
| [ops/04-ssh-login.py](../ops/04-ssh-login.py) | BatchMode 公钥登录并核对 uid＝0 |
| [ssh/README.md](../ssh/README.md) | 本机密钥与可信主机配置 |

把本机私钥放到配置 `identity_file`（默认 `ssh/id_ed25519`）。不要提交私钥。

```powershell
# 在仓库根目录执行
python ops\04-ssh-login.py
```

通过：`uid=0(root)` 且退出码 0。主机公钥必须预先通过可信渠道核验并写入本机 `ssh/known_hosts`；脚本使用严格校验，未知或变更的主机钥会被拒绝。

主机公钥检查：

```powershell
ssh-keygen.exe -lf ssh/known_hosts -E sha256
```

Windows 上不要对 stdin 调用 `os.set_blocking`（会 WinError 5）。代理用线程拷贝 stdio。
