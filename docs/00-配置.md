# 配置

操作文件：

| 文件 | 作用 |
|---|---|
| [ops/config.example.json](../ops/config.example.json) | 入库模板，不含设备标识的配置模板 |
| `ops/config.json` | 本机覆盖，已 gitignore，从 example 复制 |
| [ops/config.py](../ops/config.py) | 读取配置，路径相对仓库根 |

先复制：

```powershell
Copy-Item ops\config.example.json ops\config.json
```

复制后填写本机参数，模板中的空值不能用于连接：

- SSID：填写目标热点名称（`ssid`）
- 电脑地址：填写 `bind_ip`，源端口 **7878**
- 车机地址：填写 `host`；端口为 `testiface_port`（testiface）与 `ssh_port`（sshd）
- 拉起命令：`mkdir -p /var/run/sshd; chmod 755 /var/run/sshd; /usr/sbin/sshd -f /etc/ssh/sshd_config_readonly -t; /usr/sbin/sshd -f /etc/ssh/sshd_config_readonly`
- 期望回包 `9387abcd0000000082e3010113`（内含 `82 e3 01 01`）

改 IP / SSID 只改 `config.json`，不要改脚本里的字面量。
