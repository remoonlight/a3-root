# 探测 15500 与 22

操作文件：[ops/02-tcp-probe.py](../ops/02-tcp-probe.py)

源端口必须是配置 `bind_port`（7878）。防火墙放行的是 `--sport 7878`，不是任意客户端端口。

冷启动常见结果：

| 目标 | 结果 |
|---|---|
| `:22` | 拒绝 10061（sshd 未起） |
| `:15500` | 接通，无 banner（testiface 在） |

```powershell
# 在仓库根目录执行
python ops\02-tcp-probe.py 22
python ops\02-tcp-probe.py 15500
```

成功握手后该 4 元组会进 TIME_WAIT。同一源端口立刻再连会 WinError 10048。先跑 [ops/wait_7878.py](../ops/wait_7878.py)，或等配置 `time_wait_s`（默认 120）。

探测只确认 TCP。ACK 和 `id` 都不是这一步的验收。
